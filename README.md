# 🚀 Portech Website

Portech is a modern portfolio and service website designed for showcasing web development services and projects.

## 📌 Project Overview
This website provides a clean and professional interface where users can:
- View company information
- Explore services
- Check portfolio projects
- Contact the company
- Register and login to the platform

## 🌐 Pages Included
- Home Page
- About Page
- Services Page
- Portfolio Page
- Contact Page
- Login Page
- Register Page
- Forgot Password Page

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Node.js (Backend)
- MySQL (Database)

## 🎨 Features
- Modern UI Design
- Responsive Layout
- Animated Backgrounds
- User Authentication System
- Clean Navigation System
